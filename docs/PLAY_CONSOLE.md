## 1. Создать приложение (2 минуты, только вручную)

Play Console → «Создать приложение».

| Поле | Значение |
|---|---|
| Название | Novalith: Cosmic Merge |
| Язык по умолчанию | Английский (США) — en-US |
| Приложение или игра | Игра |
| Платное или бесплатное | Бесплатное |
| Декларации | отметить обе |

Имя пакета `com.novalith.game` закрепится при первой загрузке AAB и больше не меняется.

## 2. Загрузить страницу и сборку скриптами

После шага 1 API начинает видеть приложение:

    cd ~/novalith
    ~/play-console-api/.venv/bin/python tool/play/store.py              # проверка, ничего не меняет
    ~/play-console-api/.venv/bin/python tool/play/store.py --commit     # тексты, иконка, баннер, скриншоты
    ~/play-console-api/.venv/bin/python tool/play/release.py ~/novalith-release/app-release.aab internal --commit

Если API откажет в первой загрузке сборки (у совсем нового приложения так бывает), загрузите
AAB вручную: «Тестирование → Внутреннее тестирование → Создать выпуск».

При первой загрузке Play предложит «Подпись приложений в Google Play» — согласиться.

## 5. Тестирование и публикация

1. **Внутреннее тестирование** — добавить свою почту в список тестировщиков, открыть ссылку
   на телефоне, установить из Play. Это главная проверка: сборка из Play подписана Google и
   ведёт себя так же, как у будущих игроков.
2. **Закрытое тестирование** — для личного аккаунта, созданного после ноября 2023 года, нужно
   12 тестировщиков в течение 14 дней, прежде чем откроется доступ к рабочей версии.
3. **Страны** — выбрать регионы в настройках трека (по умолчанию не выбрано ничего).
4. **Рабочая версия** — после одобрения доступа.

## 6. Покупка «Убрать рекламу»

«Монетизация → Товары → Товары в приложении → Создать»: идентификатор **`remove_ads`**,
название «Remove ads», цена на ваш выбор, активировать. Раздел открывается после загрузки
первой сборки. Пока товара нет, кнопка в игре просто скрыта.

## 7. AdMob

- **Форма согласия для Европы:** AdMob → «Конфиденциальность и сообщения» → создать и
  опубликовать сообщение по GDPR для приложения Novalith. Без него в Европе реклама не
  запросится.
- **Тестовое устройство:** AdMob → «Настройки → Тестовые устройства» → добавить свой телефон.
  Иначе собственные клики по боевой рекламе могут привести к блокировке аккаунта.
- **Привязка к магазину:** после публикации — AdMob → приложение → «Добавить магазин».
- **Формат наградной рекламы:** сейчас используется блок «Межстраничный с вознаграждением»
  (`…/9380016124`). Игра показывает его только по нажатию кнопки, на экране, где награда
  названа и есть отказ. Если захотите классический формат «С вознаграждением», создайте такой
  блок и скажите мне его ID — переключение занимает одну настройку сборки.

## Частые причины отклонения — что проверено

| Риск | Состояние |
|---|---|
| Целевой уровень API | 36 — выше текущего требования |
| Поддержка страниц памяти 16 КБ | есть, проверено по APK |
| Сборка подписана отладочным ключом | нет — подписана ключом загрузки |
| Тестовые ID рекламы в выпуске | нет — боевые ID из секретов репозитория |
| Разрешение AD_ID без декларации | декларация — в шаге 3 |
| Нет политики конфиденциальности при наличии рекламы | опубликована |
| Скриншоты с прозрачностью или не того размера | 1080×1920, 24-битный PNG |
| Реклама во время игры или сразу при запуске | нет: только между партиями и по кнопке |
| Приложение падает при запуске | каждая сборка запускается на эмуляторе в CI |
