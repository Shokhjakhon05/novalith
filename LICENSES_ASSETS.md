# Asset licences

Novalith ships no third-party artwork or recordings.

| Asset | Origin | Licence |
|---|---|---|
| Celestial bodies, backgrounds, particles, UI | Drawn at runtime by `lib/game/sprites.dart` and `lib/ui/` | Own work |
| App icon, adaptive icon layers, splash mark, logo, store graphics | Generated by `tool/gen_brand.py` | Own work |
| All sound effects and the music loop (`assets/audio/`) | Synthesised by `tool/gen_audio.py` | Own work |
| Exo 2 typeface (`assets/fonts/Exo2.ttf`) | The Exo 2 Project Authors, https://github.com/googlefonts/Exo-2.0 | SIL Open Font License 1.1 (`assets/fonts/OFL.txt`) |
| Material Icons (bundled by Flutter) | Google | Apache License 2.0 |

Re-create the generated assets with:

    python3 tool/gen_brand.py   # needs Pillow
    python3 tool/gen_audio.py   # needs ffmpeg
