# Novalith - Cosmic Merge

A portrait, one-thumb physics merge game for Android. Drop a celestial body, match two of a
kind, and they merge into the next evolution: stardust -> meteor -> asteroid -> moon -> planet ->
gas giant -> white dwarf -> sun -> red giant -> neutron star -> black hole -> galaxy. Two
galaxies make a Big Bang.

Flutter 3.47.5 + Flame. Offline-first, no backend. All art and sound are generated by code.

## Layout

| Path | What lives there |
|---|---|
| `lib/core/` | The game itself in pure Dart: physics, merging, fair spawner, scoring, saves, rewards, daily systems, ad pacing. No Flutter imports - everything is unit-tested without a device. |
| `lib/core/balance.dart` | **Every tunable number.** Rebalance the game here. |
| `lib/game/` | Rendering: procedural sprites and the Flame board with all feedback effects. |
| `lib/ui/` | Screens: menu, play, shop, collection, achievements, settings. |
| `lib/services/` | Optional subsystems behind interfaces: save file, audio, haptics, ads, purchases, analytics. |
| `lib/l10n/` | 16 languages as plain maps. |
| `test/` | Unit, property/stress, balance (bots) and end-to-end widget tests. |
| `tool/` | Asset generators (`gen_brand.py`, `gen_audio.py`) and the balance probe (`sim.dart`). |
| `docs/` | Balance report, verification matrix, privacy policy, Play Store material, checklists. |

## Working on it

Heavy builds are not run locally. Edit, run the light checks, push, and let CI build:

    flutter analyze
    flutter test                      # ~4 minutes; NOVALITH_GAMES=1000 for the full volume
    gh workflow run ci.yml            # format, analyze, all tests, release APK + AAB
    gh run watch

CI is started by hand on purpose (see `DECISIONS.md`, #17). Its artifacts are the release APK,
the App Bundle and the balance report.

## Configuration (nothing secret is in the repository)

| What | How | Default |
|---|---|---|
| Rewarded / interstitial ad unit ids | `--dart-define=REWARDED_AD_UNIT_ID=...`, `--dart-define=INTERSTITIAL_AD_UNIT_ID=...` (CI: repository secrets of the same names) | Google test units |
| AdMob app id | Gradle property or env `ADMOB_APP_ID` (CI secret) | Google test app id |
| Application id | Gradle property `NOVALITH_APPLICATION_ID` | `com.novalith.game` |
| Remove-ads product id | `--dart-define=REMOVE_ADS_PRODUCT_ID=...` | `remove_ads` |
| Upload key | CI secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` | debug key |

## Debug tools

In debug builds the play screen has a bug button: spawn any piece, spawn a pair, clear the
board, force game over, FPS / entity counters, fixed seed, reset save. The whole panel is behind
`kDebugMode`; CI checks that its strings are absent from the release binary.
